We have recently updated [ANTs](http://stnava.github.io/ANTs/ "ANTs website") to perform processing of perfusion ASL images.  The pipeline is designed to be consistent with the antsCorticalThickness pipeline for computing cortical thickness and incorporates state-of-the-art methods for correcting for motion and other confounds.  Learn more about the script [here](https://github.com/stnava/ANTs/blob/master/Scripts/antsASLProcessing.sh "antsASLProcessing.sh script").
