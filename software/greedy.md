# Greedy

{%
  include figure.html
  image="images/software/greedy.jpg"
  width="60%"
%}

Greedy is a tool for fast deformable medical image registration. It was developed to
provide a very fast CPU-based registration tool for applications and pipelines in which
many images have to be registered in parallel, such as multi-atlas segmentation in
[ASHS](/software/ashs.html). Greedy supports affine and deformable registration,
and is also available as a Python package. Greedy development is led by
[Paul Yushkevich](/members/paul-yushkevich.html).
