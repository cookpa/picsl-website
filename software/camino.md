# Camino

![squid_text_post_size](/images/wp/2013/06/squid_text_post_size.png)
Camino is an open-source toolkit for diffusion MRI simulation and image processing. The PICSL contribution to the tool is led by Philip Cook and focuses on image reconstruction pipelines and tractography.
See the [Camino home page](http://camino.org.uk) for documentation and to obtain the code.
