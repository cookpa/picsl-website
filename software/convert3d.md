# Convert3D

{%
  include figure.html
  image="images/software/convert3d.jpg"
  width="60%"
%}

Convert3D (C3D) is a command-line image processing tool that complements
[ITK-SNAP](/software/itk-snap.html). It was originally developed to convert between 3D
image formats, and has become a Swiss army knife for medical image processing: resampling,
filtering, thresholding, arithmetic and many other operations can be chained in a single
command. Convert3D is also available as a Python package. Convert3D development is led by
[Paul Yushkevich](/members/paul-yushkevich.html).
