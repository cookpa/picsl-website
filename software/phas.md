# PHAS

{%

The PICSL Histology Annotation System (PHAS) is a web-based archive for large collections
of digital histopathology images, and a platform for annotating them and training deep
learning classifiers. Because the data live in a central repository and are viewed in a
web browser, annotation can easily be crowdsourced. PHAS development is led by
[Paul Yushkevich](/members/paul-yushkevich.html).
